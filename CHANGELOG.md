# Изменения

## v1.0.29 — 0.1.2-beta.43
- Полное меню «...» у треков в поиске, плейлистах и во всех вкладках библиотеки.
- Треки с несколькими артистами видны на странице каждого из них; «A, B» и «A; B» разделяются на отдельных артистов.
- На странице артиста можно добавить альбом и обложку треку без неё; фото артиста берётся из обложек, если своего нет.
- «Что слушают друзья» на главной, если на сервере есть другие пользователи.
- Мгновенная синхронизация между устройствами через WebSocket.
- Сервер хранит полную историю прослушиваний (для итогов).
- Анимации переходов между вкладками и в списках.

## v1.0.28 — 0.1.2-beta.42
- Новый экран статистики: сетка по неделям, прослушивание по часам, подробности по нажатию.
- Сопряжение с сервером в одно касание из браузера телефона; QR для обычных пользователей.
- Гости больше не могут менять общую библиотеку.
- Скачанные треки остаются, если отвязать сервер.
- Мини-плеер не листается туда, где нет трека; клавиатура больше не перекрывается нижней панелью.
- Исправлена двойная пауза при кроссфейде.
