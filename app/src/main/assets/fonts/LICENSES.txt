Шрифты для иероглифов (CJK) - SIL Open Font License 1.1, (c) Google LLC (Noto Project).
Полный Noto Sans CJK/SC/TC/JP/KR - несколько МБ на язык даже в одном начертании (десятки тысяч
иероглифов), поэтому здесь не полные шрифты, а обрезанные по частоте символов подмножества:
инстанцированный статический wght=400 (Noto Sans CJK - variable font, из него собирается один
вес), урезанный до символов, которые Google Fonts сам отдаёт первыми срезами (css2 API режет шрифт
на unicode-range куски по частоте использования - взят префикс срезов, не весь диапазон):
  Noto Sans SC (упрощённый китайский)  ~3000 самых частых иероглифов
  Noto Sans TC (традиционный китайский) ~3000 самых частых иероглифов
  Noto Sans JP (японский)               ~2600 кандзи + вся хирагана/катакана
  Noto Sans KR (корейский)              ~2600 слогов хангыля
Редкий символ вне подмножества по-прежнему рисует системный шрифт (как было и без этой фичи) -
разница только в том, что покрытые подмножеством символы теперь в выбранной пользователем
гарнитуре, а не в системной.
