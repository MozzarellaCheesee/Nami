Где находится ваша музыка?

Укажите папку с аудиофайлами на сервере (например: /var/lib/nami/music). Если музыки пока нет, шаг можно пропустить — треки можно будет загрузить со смартфона.

Доступ вне дома

Как подключаться к серверу, когда вы не в домашней сети. Приложение всё равно сначала пробует локальный адрес - этот нужен только «в дороге».

На сервере: tailscale up, затем по желанию tailscale serve --bg --https=443 http://localhost:PORT.

На сервере: cloudflared tunnel create nami, cloudflared tunnel route dns nami music.example.com, cloudflared tunnel run --url http://localhost:PORT nami.

Введите ваш домен (A-запись должна указывать на IP этого сервера). Nami автоматически откроет порты 80/443, настроит Reverse Proxy Caddy и активирует бесплатный SSL-сертификат Let's Encrypt!
